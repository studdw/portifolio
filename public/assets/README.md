# Imagens dos projetos

Coloque aqui as capturas de tela de cada projeto funcionando.
Os nomes precisam bater com os caminhos definidos em `src/data/content.js`.

| Projeto | Arquivos esperados |
|---|---|
| Sistema de Pesquisa de Preços | `precos-01.png`, `precos-02.png`, `precos-03.png` |
| Dashboard de Budget | `budget-01.png`, `budget-02.png`, `budget-03.png` |
| Automação de Pagamentos | `pagamentos-01.png`, `pagamentos-02.png`, `pagamentos-03.png` |
| Inteligência de Mercado | `mercado-01.png`, `mercado-02.png`, `mercado-03.png` |


Recomendações:
- Proporção **16:10** (ex.: 1600 x 1000 px) para o recorte ficar uniforme.
- `.png` para telas de sistema e dashboards.
- Enquanto a imagem não existir, o site mostra automaticamente um placeholder
  com a legenda e o caminho do arquivo — nada quebra.

Para trocar legendas ou adicionar/remover imagens, edite o array `gallery`
do projeto correspondente em `src/data/content.js`.

> Atenção: não publique imagens com dados sensíveis ou confidenciais.
> Desfoque valores, nomes de fornecedores e informações internas antes de subir.
